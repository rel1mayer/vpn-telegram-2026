# Инструкция по добавлению сервиса (CONTRIBUTING)

Мы приветствуем добавление новых проверенных Telegram-ботов с VPN-доступом в наш открытый каталог.

## Критерии добавления

1. Бот должен быть **активным** и доступным в Telegram.
2. Поддержка актуальных протоколов обхода блокировок: **VLESS Reality**, **Shadowsocks 2022**, **TUIC**, **Hysteria 2**, **WireGuard (с обфускацией)**.
3. Прозрачные условия и тарифы.
4. Желательно наличие бесплатного пробного периода (триала) для проверки работоспособности пользователями.

## Как предложить изменения

1. Сделайте Fork этого репозитория.
2. Добавьте запись о вашем сервисе в файл `data/bots.json`.
3. Отправьте Pull Request с кратким описанием сервиса.
4. После автоматической проверки доступности бот будет добавлен в каталог и в базу Telegram-бота [@vpnhab_bot](https://t.me/vpnhab_bot).

Для ускоренной верификации и приоритетного размещения в разделе «ТОП-5» пишите в бота: [@vpnhab_bot](https://t.me/vpnhab_bot?start=collab).
